# 姻缘祈福树 · 夜色古院

一个纯程序化生成的 Three.js 夜景场景：**夜色中式古庭院**中的一棵**姻缘祈福树**。
打开页面时画面中央只有一株会呼吸的迷你小树苗，**点击画面**后它开始生长 —— 粗糙遒劲的老树干、
层层岔开的枝杈、满树艳红的花团，随后挂满红绸带、许愿姻缘牌、黄铜同心锁、小红福袋与迷你纸灯笼。
长成之后微风永续循环：枝条轻摇、绸带与吊牌柔软摆动、花瓣慢悠悠盘旋飘落。

> 全部几何、贴图与动画都是代码生成的，**不加载任何外部模型或图片**，只从官方 CDN 引入 three.js。

---

## 一、运行方式

三种方式都能跑（已实测）：

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 直接双击 | 双击 `index.html` | ✅ 可用。`main.js` 写成经典脚本 + 动态 `import()`，因此 `file://` 下也能加载 |
| 本地服务 | `python -m http.server 8000` 然后访问 `http://localhost:8000` | 推荐，行为与线上一致 |
| GitHub Pages | 把三个文件推到仓库，Settings → Pages 选分支根目录 | 打开生成的链接即可 |

> 说明：浏览器禁止 `file://` 页面加载**本地 ES module**（CORS）。所以 `main.js` 里没有静态 `import`，
> 而是在 async 函数中 `await import('three')`，由 `index.html` 的 import map 把裸模块名解析到 unpkg 的官方构建。
> 这样双击打开、本地服务、GitHub Pages 三种情形都能运行。

## 三、交互

* **点击/轻触画面** → 开始生长（生长总时长 **11.5 秒**，落在要求的 9~13s 区间内）
* **按住拖拽** → 旋转视角（OrbitControls，带阻尼）
* **滚轮 / 双指** → 缩放
* 没有按钮、没有弹窗、没有多余面板；只有一句会淡出的提示文字，点击后不再出现
* 键盘 `空格` / `回车` 等同于点一下就生长

## 四、实现要点

### 1. 分形老树（程序化生成，无外部模型）
* **8 层（order 0~7）递归分形**：每层按 `ORDER_LEN` / `ORDER_RAD` 表决定枝长与半径，
  主干短粗、主枝壮、逐层迅速变细变密 —— 内侧 2~3 层几乎不开花，**骨架外露**，这就是"层次感"的来源
* 锥度用**几何插值**（`r = r0 · (r1/r0)^(t^0.88)`）而非线性，根部略胖、末端收得快，更像真实老枝
* **肘部扭结**：每段有一定概率发生一次 0.10~0.32 rad 的突转向，形成老枝的年节折感
* 主干第一根分枝几乎直立（避免树冠中心空），其余按黄金角散布；主枝先向外压、细枝再上扬 → 伞形树冠
* **枝梢收尖**：到梢的最后一段沿轴再收 3 圈到 0，长度约 **5.2 倍末端半径**，
  并把法线按锥面斜率倾斜（否则锥面会按圆柱受光、看起来像"贴片"）；断枝残桩则收成钝头
* **断枝残桩** 11 处（老树被折断的枝茬）、**结疤** 5 颗（半埋进树皮）、**板根** 9 条（细长、贴地铺开成鳍状）
* 分叉处补低模球体藏接缝
* 顶点置换：**环向用整数周期 + 频率低于采样率**（避免混叠成一坨大石块），
  横枝改用"沿枝长"的噪声坐标（否则整根枝截面不变，就是一块板条）；幅度只占半径的 1~2 成，细纹理交给法线贴图

### 2. 程序化贴图（全部 canvas 现场生成）
* **树皮**：高度场刻意以**大尺度**为主（树皮板块 + 6 条纵向棱 + 纵向深沟 + 细颗粒），
  再经 Sobel 转成切线空间法线贴图；另有颜色贴图与粗糙度贴图（裂隙更粗糙）
* **青石板地面**：分块基色差异 + 灰缝下沉 + 斑驳噪声，同样配法线/粗糙度
* **许愿牌**：一张 256×512 图集，上部是牌面（暗红底 + 金色描边 + **淡淡的竖向"姻缘天定"与底部小字**），
  中部是红绸（挂绳），下部是金色流苏；几何按 UV 区域分别取用，一次 draw call 搞定整块牌子
* **花瓣**：贝塞尔曲线勾勒的瓣形 + 径向渐变 + 淡淡瓣脉
* **格栅窗**：方格 + 菱形纹样，只做很弱的自发光

### 3. 挂件（全部代码生成）
| 挂件 | 做法 |
| --- | --- |
| 红绸带 | 22 段 × 5 列的**弧面布片**（横向法线渐变 → 有柔软的高光），带扭转与收窄 |
| 许愿姻缘牌 | 牌面 + 挂绳 + 结 + 流苏，图集贴图，**牌面有淡淡文字纹理** |
| 黄铜同心锁 | 半环锁梁 + 压扁锁体 + 锁孔，顶点色区分铜色/暗色，金属度 0.88 |
| 小红福袋 | 袋身 + 金色束口 + 流苏，顶点色区分红布与金饰 |
| 迷你纸灯笼 | 收腰球体 + 上下灯盖 + 吊绳 + 流苏，暗色漫反射 + 暖橙自发光（避免被自身点光烧白） |

挂件沿枝条加权随机悬挂（越靠外越多），吊点上方留绳，向下垂挂。

### 4. 生长动画（GPU，CPU 零开销）
* 每个顶点带 `aOrigin`（所在枝段的基部）/ `aGrow`（出现时刻）/ `aSpan`，
  顶点着色器里 `mix(aOrigin, position, smoothstep(...))` —— 枝条**从基部挤出**般生长
* 挂件与花团是实例化网格，`aGrow` 为实例属性，着色器里 `transformed *= g` —— 从悬点"长出来"
* 时间轴：主干 0→0.14，逐层递延到 0.83 长齐骨架；花团 0.35→1.0 次第开放；
  挂件 0.85→1.0 依次出现。总时长 11.5s
* 阴影用的 `customDepthMaterial` 注入同一套塌缩逻辑，否则影子会提前出现
* 点击瞬间有一次暖光涌动；灯光强度随生长渐亮

### 5. 微风与飘落（长成后永久循环）
* 风场是**位置函数**（`ph = p.x*0.35 + p.y*0.12 + p.z*0.28`）而不是随机相位，
  于是同一处的枝条、花团、挂件**同步摆动**，并且整棵树像有风浪掠过
* 枝条：按层数与高度加权（主干几乎不动，梢头最柔）位移，幅度刻意压低（`windBase = 0.115`）
* 悬吊物：绕悬点做**钟摆旋转**（约 3~5°）+ 绸带沿长度叠加柔性波动
* 花瓣：260 片在 CPU 端循环下落（慢，0.2~0.46 单位/秒）+ 盘旋漂移 + 自转

### 6. 夜色与光
* 环境极暗：半球光 0.055、月光方向光 0.13，其余全靠树上灯笼的暖黄光
* 主光是一盏唯一投影的暖色聚光（2048 阴影贴图），另有正面补光、树冠内多盏灯笼点光、
  树干前的低灯笼光（点光用 `decay≈1.35~1.6` 的柔性衰减，避免近处几何被 1/d² 烧成白条）
* 后期：`RenderPass → UnrealBloomPass → OutputPass → 自定义暗角/冷调 pass`
  （Bloom 0.58 / radius 0.44 / threshold 0.72，只让灯笼与高光泛光）
* 光晕 Sprite + 8 片交叉的柔和光束面片 → 朦胧体积光；`FogExp2` 压出夜色纵深
* 抗锯齿开启，`ACESFilmic` 色调映射

### 7. 庭院
青石板地面、三面围墙 + 檐口、廊柱与柱础、格栅窗、台明阶石、廊下灯笼（4 盏），
都在雾与暗光里只剩轮廓，起到框景作用。

## 五、性能

* 树干约 36.7 万顶点（8 层分形，细枝截面 7~22 边）、花团约 2.0 万个实例（每个 20 面）、挂件约 260 个实例
* 段数设有保险丝（6200 段），避免随机种子导致几何爆量
* 花团/挂件/花瓣各自只有 1 个 draw call；阴影只渲染树本体
* 像素比上限 1.75；窗口尺寸变化自动重建渲染尺寸

## 六、调试参数（可选，不影响正常使用）

| 参数 | 作用 |
| --- | --- |
| `?grow=0.65` | 跳过等待，直接把生长进度定在 0.65 并停住（用于截图/预览） |
| `?autostart=1` | 不需要点击，加载后自动开始生长 |
| `?still=1` | 隐藏"轻触画面"提示 |
| `?nobloom=1` | 隐藏花团，只看枝干骨架（检查枝形用） |

`shots/` 下的阶段截图即由 `?grow=` 生成。重新批量截图：

```powershell
# 若提示脚本被策略阻止，用：
powershell -ExecutionPolicy Bypass -File tools\render.ps1 -Tag demo -Stages 0,0.45,1
```

## 七、可调参数速查（都在 `main.js` 顶部 `CFG` 或常量表里）

| 位置 | 含义 |
| --- | --- |
| `CFG.growDuration` | 生长总时长（秒） |
| `CFG.windBase` | 风力（越小越"轻柔"） |
| `CFG.seed` | 随机种子 —— 换一个数字就是另一棵形态不同的树 |
| `CFG.maxOrder` | 分形层数（越大枝越细密，也越吃性能） |
| `ORDER_LEN` / `ORDER_RAD` | 每层枝长 / 半径 |
| `ORDER_TIME` | 每层出现的进度区间 |
| `keySpot` / `barkLights` / `lanternLights` | 主光 / 树干补光 / 灯笼点光强度 |
| `UnrealBloomPass` 三个参数 | 泛光强度 / 半径 / 阈值 |
| `FLOWER_P` | 每层枝条开花的概率（内侧低＝骨架外露，外侧高＝花云密） |
| `buildFlowers` 里的 `n`、`scl` | 每处花团数量与花团大小 |
